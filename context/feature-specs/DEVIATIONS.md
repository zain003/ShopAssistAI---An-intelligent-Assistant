# DEVIATIONS.md — Implementation Assumptions & Runtime Drift Log

This file is a running log of ambiguities, edge cases, and reasonable assumptions made during implementation. 

## Protocol
Whenever an implementer encounters a case not explicitly covered by a feature spec:
1. Do **NOT** silently guess.
2. Make the smallest reasonable assumption needed to proceed.
3. Record it immediately in the log table below.
4. Continue implementation without blocking, **unless** the assumption affects a core schema in `000-shared-contracts.md` (in which case **STOP** and flag for human review).
